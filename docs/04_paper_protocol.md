# 论文实验、可支持主张与待补材料

## 可以据现有实现描述

- 双臂灵巧手的分段任务执行、交接、保持使能回位和A/B路线切换。
- 状态历史为主、显式标量进度和顶视CNN残差的动作块策略。
- 有限邻域实测进度恢复，及其对特定历史卡点的离线复现效果。
- 教师执行数据采集、离线阶段重标注与微调流程。
- 模型、运行时调整、实测状态与实际动作分别记录的实验追溯机制。

这些是实现事实，不自动构成创新性或优于现有工作的证据。相关工作与文献尚需检索核验。

## 不能直接宣称

纯视觉控制；无示范参考；未见场景泛化；严格在线强化学习；人工同查询DAgger；抓取力控制得到验证；所有记录均成功；程序完成等价于封口质量合格。

## 主实验建议

冻结一个系统版本后，在固定初始条件下做独立重复试验。预先写明成功判据、计划次数、人工干预定义及中断处理方式。报告成功次数/总次数、完成时间分布、干预次数、失败阶段和故障类别；不要只保留好看的录像。

任务一子指标：抓取、交接、放置释放。任务二子指标：桌面抓取、封口设备定位/操作、封口后抓取、放置释放。封口质量另行检查。复位成功另记。

曾用于反复调参的运行属于开发过程。独立测试应在不再调参的冻结版本上另做；训练/验证/测试按完整episode划分，避免相邻帧泄漏。

## 优先消融

| 问题 | 对照 | 指标 |
|---|---|---|
| 进度是否必要 | 无进度 / 有进度 | 停滞、漂移、完成率 |
| 恢复逻辑是否有效 | 相同权重下恢复关闭 / 开启 | 卡点次数、恢复次数、误推进 |
| 视觉是否被利用 | 真实 / 遮蔽 / 打乱图像，先离线 | 动作变化、实机成功率（若执行） |
| 纠正数据是否有帮助 | 微调前 / 后，相同测试协议 | 两次抓杯的子阶段成功率 |
| 系统路线差异 | A / B | 时间、成功率、教师/人工介入比例 |

“camera_scale=1”和存在CNN分支不是视觉有效性的充分证据。A/B也不都是纯网络对照，应披露架构及教师参与差异。

## 写作材料清单

设备型号、关节映射与单位；相机布局与标定；杯子/设备尺寸和位置；计算平台和软件环境；网络结构、损失和训练超参；逐次试验表；全程外部录像及时间对应；成功/失败关键帧；轨迹、进度、误差和控制来源曲线。

已有初始状态相机素材位于本地paper/figures。还需完整外部录像及正式实验图表。本仓库没有编造性能表、成功率或相关工作引用。

## 推荐论文结构

问题与场景 → 装置 → 数据采集 → 方法与四路线边界 → 训练及纠正 → 独立实验与消融 → 失败分析 → 局限与可复现材料。
