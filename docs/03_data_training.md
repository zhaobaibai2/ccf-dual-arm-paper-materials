## 网络运行数据

- `predictions.jsonl`：观察索引、推理时延、进度、预测文件路径及接受状态等。
- `observations/*.npz`：图像、状态历史、预测动作块、事件等，具体字段随版本变化。
- `owner_trace.jsonl` 或 `visual_cup/<job>.jsonl`：实测状态、实际发送参考、教师动作、控制来源、结束原因。
- `model_meta.json / job.json / outcome.json`：模型标识、任务关联和程序结果。

后期B路线只采真实top；虽然存储数组保留3个槽位，腕部槽位是零占位。图像文件存在不等于该槽位具有真实观测。

## 任务二纠正与v24微调

主采集 `task2_best_correction_20261010_012349` 保存2778次网络观察和5558次独立采集观察，约277.87秒；日志报告无丢弃/写入错误，引用帧齐全。控制来源计数：teacher_cycles=27000、corrected_policy_cycles=10，最终cancelled_holding，控制日志正常end。

教师来源明确为 `CONTROL_TEACHER, not human teleoperation`。流水线：

1. 保存实际状态、图像、网络查询与教师执行轨迹。
2. 从日志语义阶段及既有阶段终点重建监督上下文。
3. 排除未知阶段、过量终端保持、跨阶段未来标签和无效窗口。
4. 生成2505个带逐通道监督掩码的窗口。
5. 在v23权重基础上离线微调得到v24，保留训练日志及前后误差报告。

`same_query_dagger=false`、`goal_reconstructed_offline=true`。正确描述是“基于教师实际执行数据的离线重标注与微调”。不能改称在线实时更新策略或人工同查询DAgger。

2505个窗口SHA256均验证一致，源控制轨迹哈希与训练索引一致。报告 `independent_validation=false`；训练集拟合改善不是独立泛化证据。

- 若干运行有观察与控制日志但缺少outcome；有一条任务三记录存在截断JSON。具体见核查表。

所有数据保留原始字段。`physical_task_success=false`可能表示没有自动验证，不能直接当作实物失败，也不能事后覆盖成true。另加人工审核表记录结果及依据。
