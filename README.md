## 材料范围

- `docs/`：中文技术说明，可直接作为论文写作依据，但需按实验结果审核措辞。
- `evidence/`：版本、数据核查、训练报告与环境信息；其中机器路径是来源定位记录。
- `reference_code/`：关键算法源码的只读参考副本，不是完整可部署机器人程序。
- `templates/`：试验、消融、数据划分、录像、设备、结果审核模板。

本仓库不包含完整权重、原始RGB/深度流或机器人驱动环境。完整本地快照位于 `ccf/paper/versions/task12_AB_20261018_104551`。源码中的绝对路径保留用于追溯。

## 写作时必须保留的事实

- 任务一 A 是轨迹控制，不能称为学习策略。
- 任务二 A 中教师控制参与实际动作，不能把结果全归于网络。
- v24使用教师实际执行数据进行离线重标注微调，不是人工同查询DAgger或运行中在线更新权重。
- 后期 B 路线是真实顶视输入，腕部槽位为占位；不能写成三路真实视觉推理。
- 程序 `passed` 和现场实物成功不是同一指标。成功率应来自独立、完整、人工复核的试验表。
- 同一模型SHA下修改手型覆盖、进度恢复或控制参数，仍然是不同系统版本。
